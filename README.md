# NEVIndia — AssemblyGPT & ChainMind

An AI-powered dashboard and live assistant for New Energy Vehicle (EV & Hydrogen) assembly and supply chain intelligence.

## Features
- **AssemblyGPT**: Voice-enabled AI mentor for factory workers (Battery, Motor, Fuel Cell, Integration).
- **ChainMind Predictor**: Market intelligence for battery materials (Lithium, Graphite) and competitor tracking.
- **NEV Landscape**: Comprehensive data on India's EV and Hydrogen policy and growth.

## Tech Stack
- **Frontend**: HTML5, Vanilla CSS, JavaScript (Modules)
- **AI Engine**: OpenAI (via OpenRouter)
- **Background**: Dynamic Particle Canvas, Scroll-Reveal Animations

## Setup
1. Clone the repository.
2. Create a `.env` file with your `OPENAPIKEY`.
3. Run `python build_env.py` to synchronize the configuration.
4. Open `index.html` via a local server (e.g., `python -m http.server`).
